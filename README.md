A [make.fun](https://make.fun) entry for **One Line, One Chill**: one sentence of horror, under 200 characters, that has to frighten a reader in one breath.

`main.ts` runs deterministically — no network, no input, no randomness, no clock — and writes the line to `/output/entry.txt`, printing exactly that line to stdout.

## The line

> The lifeguard counted heads: twenty-three swimmers, twenty-four shadows — the extra one has been doing laps underwater since Tuesday, never coming up for air.

## Run

```sh
node main.ts
```
